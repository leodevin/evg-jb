# EVG de JB — Châteauneuf-du-Pape, 9–11 octobre 2026

Le site du week-end. Deux pages HTML autonomes, sans build ni dépendance :
ouvre n'importe quel fichier dans un navigateur, ça marche.

| Page | Fichier | Contenu |
|---|---|---|
| Roadbook | `index.html` | Le planning des trois jours, la to-do, les infos pratiques |
| Olympiades de la Pêche | `olympiades.html` | Le samedi après-midi : règles, 10 épreuves, barème, scores, liste de courses |

## En ligne

Publié via GitHub Pages depuis la branche `main`, à la racine.
Un `robots.txt` et une balise `noindex` empêchent l'indexation par les moteurs
de recherche — l'URL reste publique pour qui la connaît.

## Modifier

Tout est en dur dans chaque fichier HTML (styles et scripts inclus).
Pour changer un horaire ou une épreuve : édite le HTML, commit, push.
GitHub Pages redéploie tout seul en une minute.
